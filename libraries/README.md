# Put the library zips here

Download the **EXS24** version of each instrument from the CATSNU GUGAK page,
<http://en.catsnu.com/Project/GugakVSTi.aspx>, and copy the zips into this folder with their
original names. `./build.sh` only reads them; it never changes or deletes them.

```
18-string_geum exs24.zip
25-string_geum exs24.zip
daeajaeng (forsythia bow) exs24.zip
daeajaeng (horse tail hair bow) exs24.zip
daegeum (unified) exs24.zip
dangpiri exs24.zip
danso exs24.zip
geomungo exs24.zip
haegeum exs24.zip
hun exs24.zip
hyangpiri exs24.zip
janggu exs24.zip
jeongakdaegeum exs24.zip
jeongakgayageum exs24.zip
pyeongyeong exs24.zip
pyeonjong exs24.zip
sanjodaegeum exs24.zip
sanjogayageum exs24.zip
sepiri exs24.zip
soajaeng exs24.zip
sogeum exs24.zip
taepyeongso exs24.zip
yanggeum exs24.zip
```

Any subset works; instruments whose zip is missing are left out of the build.
